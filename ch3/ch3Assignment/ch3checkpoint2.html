1. Embedded Styles

When to use: Best when styling a single, specific web page that requires unique design rules not shared across the rest of the site.

Location: Placed inside the <head> section of the HTML document within <style> tags.

2. External Styles

When to use: Best for multi-page websites to ensure a consistent look and feel across all pages.

Location: Stored as an independent .css file and linked inside the <head> section using a <link> tag.

3. Code to Link External Stylesheet "color.css"

Place this code inside the <head> element:

<link rel="stylesheet" href="color.css">
