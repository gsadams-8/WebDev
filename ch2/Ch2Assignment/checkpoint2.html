Chapter 2: HTML Elements & Structure

1. Heading Elements

Heading elements (<h1> through <h6>) organize text hierarchically. Heading level 1 (<h1>) represents the most important heading, while level 6 (<h6>) represents the least important heading. Browsers display heading elements in bold font with empty space above and below.

2. Unordered Lists vs. Ordered Lists

Unordered List (<ul>):
Displays a bullet or list marker before each item (<li>) in no specific order.
Ordered List (<ol>):
Displays a numbering or lettering system to itemize information sequentially.

3. Purpose of the Blockquote Element

The <blockquote> element is used to indent a block of text for special emphasis, configuring empty space above and below the text.

Chapter 2: Links & Special Characters

1. Purpose of Special Characters

Special characters (e.g., &copy; for ©, &lt; for <, and &amp; for &) allow developers to display reserved symbols accurately without breaking HTML syntax.

2. Absolute Links

An absolute link is used when linking to a page on a completely different website. Yes, the http protocol is used in the href value for absolute links.

3. Relative Links

A relative link is used when linking to pages within your own website. No, the http protocol is not used in the href value for relative links.
