Web Design Best Practices & Color Theory

1. Describe three common color schemes used in website design.
  • Monochromatic: Uses varying shades, tints, and tones of a single base color for a clean, cohesive look.
  • Complementary: Combines colors directly opposite each other on the color wheel (e.g., blue and orange) to create high dynamic contrast.
  • Analogous: Uses colors located adjacent to each other on the color wheel (e.g., blue, blue-green, and green) for harmonious visual balance.
2. Why is color contrast critical for web accessibility (WCAG Guidelines)?
High contrast between background and text ensures content remains legible for users with visual impairments, low vision, or color blindness. It also maintains readability on mobile screens viewed outdoors in sunlight.
3. What is the difference between fixed layout and fluid layout web design?
A fixed layout uses pixel-based dimensions (e.g., `width: 960px`) that remain constant regardless of screen resolution. A fluid layout uses relative percentages (e.g., `max-width: 90%`) that adapt dynamically to different browser viewport sizes.
