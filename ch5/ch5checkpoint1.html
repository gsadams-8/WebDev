Design Principles & Audience Analysis

1. List and describe the four basic principles of web design (PARC / CRAP).
  • Contrast: Emphasizes differences between elements (such as dark text on a light background) to draw attention and establish visual hierarchy.
  • Repetition: Repeats visual elements across pages (like navigation styles, fonts, and colors) to create unity and brand consistency.
  • Alignment: Places page elements along invisible horizontal or vertical grid lines to organize content logically and cleanly.
  • Proximity: Groups related items close together (like a caption beneath a photo) to visually signal their association to the user.
2. How does target audience analysis influence website design choices?
Target audience analysis dictates font selection, color schemes, image choices, layout complexity, and accessibility needs. For example, a website for children uses bright colors and large buttons, whereas a professional corporate portal uses subtle tones, structured tables, and clean typography.
3. What is the role of white space (negative space) in web page layout?
White space provides visual breathing room between sections, prevents pages from feeling cluttered, enhances text readability, and draws focus to high-priority content like headers and call-to-action buttons.
