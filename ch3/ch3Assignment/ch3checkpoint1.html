Chapter 3 Checkpoint 3.1

1. Three Reasons to Use CSS

  • Separation of Content: Keeps structural HTML separate from visual presentation styling.
  • Site Maintenance: Allows global styling changes across an entire website from one central file.
  • Greater Layout Control: Offers precise typography, spacing, alignment, and color management.

2. Configuring Both Text Color and Background Color

When changing default styles, you should always configure BOTH color and background-color together to guarantee proper visual contrast and ensure text remains readable regardless of individual browser defaults or user dark/light themes.

3. Advantage of Embedded Styles over Inline Styles

Embedded styles apply CSS rules to an entire page at once (such as all <h2> tags), eliminating the need to write repetitive style="..." attributes on every individual element as required with inline styles.
