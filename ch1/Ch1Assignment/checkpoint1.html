Chapter 1 Checkpoint Questions

Checkpoint 1.1

1. Difference Between the Internet and the Web

The Internet is the physical global network of interconnected computer networks. The World Wide Web (WWW) is the graphical user interface to information stored on computers connected to the Internet.

2. Three Events Contributing to Internet Growth

  • Removal of the ban on commercial activity.
  • Development of the World Wide Web by Tim Berners-Lee at CERN.
  • Development of Mosaic, the first graphics-based browser at NCSA.

3. Importance of Universal Design

Universal Design is the design of products and environments to be usable by all people, to the greatest extent possible, without the need for adaptation. It is critical for web developers because accessible design provides accommodations for individuals with visual, auditory, physical, and neurological disabilities.

Checkpoint 1.2

1. Client/Server Model Components

The Client (Web Browser) requests files or web pages from a server using HTTP. The Server (Web Server) continually connects to the Internet, receives requests, processes them, and sends back HTTP responses with status codes and web pages.

2. Non-Web Protocols

Two Internet protocols that do not use the Web are:

  • FTP (File Transfer Protocol): Used to transfer files between computers on the Internet.
  • SMTP (Simple Mail Transfer Protocol): Used for sending email messages.

3. URL vs. Domain Name

A Domain Name locates an organization or entity on the Internet (e.g., google.com). A URL (Uniform Resource Locator) is a type of URI that represents the complete network location of a specific resource, including protocol, web server computer name, domain name, folder, and filename.
